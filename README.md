# Shopify Sales & Customer Report - Power BI Dashboard
## Project Overview
An interactive end-to-end Power BI analytics solution designed to track, analyze, and visualize e-commerce performance. This dashboard empowers stakeholders with deep insights into transaction performance, customer purchase behavior, geographic sales distributions, and product-level trends.
## Key Performance Indicators (KPIs) & Metrics
•	Financial Performance: Tracked $4.18M in Net Sales alongside Net Average Order Value ($562.6).
•	Customer Segmentation: Analyzed a total customer base of 4,431, breaking down user loyalty into 2,392 single-order customers and 2,039 repeat customers.
•	Retention & Value KPIs: Monitored a 46% Repeat Rate, an average Purchase Frequency of 1.68, and a Customer Lifetime Value (LTV) of $943.6.
## Key Features & Visualizations
•	Sales Trends Over Time: Dual trend and bar charts illustrating revenue momentum across timelines.
•	Geographic Analysis: An interactive map visual and regional ranking breakdown covering top-performing provinces and cities across the United States.
•	Payment Gateway Distribution: Donut chart breakdown analyzing revenue share across different checkout methods (e.g., Shopify Payments, PayPal, Gift Cards, Amazon Payments).
•	Product Performance: Bar chart categorization highlighting top-selling product types (e.g., Running Shoes, Tennis Shoes, Walking Shoes).
•	Dynamic Filter Panel: Custom slicers enabling users to filter data dynamically by measures, payment gateways, and geographic provinces.
•	Page Navigator: Seamless multi-tab navigation layout allowing users to switch effortlessly between the Shopify Analysis overview and the Details Tab.
## Tools & Skills Demonstrated
•	Tool: Microsoft Power BI
•	Data Modeling & DAX: Built custom measures for advanced customer segmentation, aggregation, and financial calculations.
•	UI/UX Design: Designed a cohesive, dark-themed executive dashboard layout with standardized color coding, clear visual hierarchy, and user-friendly page navigators.
